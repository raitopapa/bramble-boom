# Bramble Boom! ゲーム仕様書（SPEC）

このファイルは「別のチャット・別のAI・別の開発者」が開発を引き継げるよう、
**動作のすべての数値とルール**を記録するものです。実装を変えたら必ずここも更新してください。
（実装の正は `src/`。数値の定義は基本 `src/core/constants.js` に集約）

## 1. コンセプト

- 対象: 幼児〜小学生を含む家族。絵本調のやさしいビジュアル、明快なルール
- 形式: 1画面固定のアリーナで「最後のひとり」を競うバトル（プレイヤー vs CPU 1〜3）
- 端末: タブレット/スマホ最優先（タッチ専用UI）、PCキーボードも対応

## 2. 画面と状態遷移

```
title ──(スタート)──▶ battle[count 3.2s] ─▶ battle[play] ─▶ battle[end]
  ▲                                           │  ▲              │
  └──────(ポーズ→タイトルへ / end→ポーズ経由) ─┘  └─(ボム/タップ)──┘ ※endからは再戦
```

- `game.state`: `'title' | 'battle'`
- `game.phase`（battle中）: `'count' | 'play' | 'end'`、`game.paused` は play 中のみ true になりうる
- ポーズメニュー: 「つづける」「タイトルへ」（←→選択、ボム/Enter決定、❚❚ボタン/Pでトグル）
- end画面: 勝者リボン＋顔チップ＋せんせき。0.9秒後からボム/タップで再戦

## 3. 盤面

- タイル 16px、盤面 **15×13**（外周は壁）。内部の偶数座標 (x%2==0 && y%2==0) は壁柱
- やわらかい箱 `B` は内部の空きマスに **62%** で配置（`SOFT_DENSITY`）
- 4隅スポーンは L字3マス（角＋右or左＋下or上）を必ず空ける
- スポーン: P1=(1,1)、CPU=(13,11)→(13,1)→(1,11) の順
- 乱数は `mulberry32(seed)`。`startMatch({seed})` で盤面を再現可能（テスト用）

## 4. 移動

- 速度: `(58 + スピード段階×13) px/秒`（CPUは難易度係数を乗算）。斜め入力は0.78倍
- 当たり: キャラは中心±5.2pxの箱。軸ごとに移動し、ぶつかったら壁ぎわへスナップ
- **コーナーアシスト**: 進行先のマスが「中心レーン」では通れる場合、垂直方向にレーン中心へ自動スライド
- 爆弾マスは通行不可。ただし**自分がいま乗っている爆弾**（置いた直後）は離れるまで通過可

## 5. 爆弾と爆風

| 項目 | 値 |
|---|---|
| 導火線 `FUSE_T` | 2.4秒（残り0.6秒で赤点滅・高速パルス） |
| 爆風持続 `BLAST_T` | 0.5秒 |
| 初期ボム数 / 上限 | 1 / 6 |
| 初期火力 `START_FIRE` / 上限 | 2 / 8 （火力=中心から各方向のマス数） |
| 誘爆 | 爆風が他の爆弾に触れると導火線を **0.08秒** に短縮 |

- 爆風は十字。壁`#`で止まる。やわらかい箱は**そのマスを含めて**破壊し、その方向は止まる
- 箱破壊時 **42%** でアイテム出現（ボム38% / ファイア38% / スピード24%）
- 露出しているアイテムに爆風が当たると消滅する
- 当たり判定: キャラの**中心マス**が爆風セルに含まれていればヒット

## 6. プレイヤーのライフ（難易度）

`src/core/constants.js DIFFICULTY`:

| key | name | hearts | cpu.spd | cpu.think | cpu.bombProb | cpu.smart |
|---|---|---|---|---|---|---|
| normal | ふつう | 1 | 1.0 | 0.15s | 0.9 | 1.0 |
| easy5 | やさしい5さい | 2 | 0.78 | 0.24s | 0.55 | 0.7 |
| easy3 | とてもやさしい3さい | 3 | 0.6 | 0.32s | 0.3 | 0.45 |

- hearts>1 のとき、被弾でハート-1＋**2.2秒無敵**（点滅）。0で脱落
- CPUのライフは常に1

## 7. CPU AI（src/game/ai.js）

`think` 間隔ごとに以下を判断（結果は次のthinkまで維持）:

1. **危険マップ**: 全爆弾の予測爆風セルに「爆発までの秒数」を記録（既存爆風は0）
2. 自分のマスが危険 → 安全マスへ **BFS**（経由マスは「到着時刻+0.45s < 爆発時刻」なら通過許可）
3. 安全なら、確率 `bombProb` で設置検討: 「隣にやわらかい箱」or「同列±火力内に敵（遮蔽なし）」かつ
   **設置後も逃げ道があるBFSシミュレーションが成立**する場合のみ設置（自爆防止）
4. それ以外の目的地: 最寄りアイテム → 箱に隣接するマス → 敵の近く（マンハッタン2以内）
5. `smart` 未満の乱数を引くと目的を放棄してうろうろ（弱さの演出）

## 8. 勝敗・ラウンド

- 制限時間 **120秒**。生存者が1人以下になった時点で終了（0人=ひきわけ、同時死亡もひきわけ）
- 時間切れ=ひきわけ。勝敗は `save.w / save.l` に累積（プレイヤー勝ち/負けのみカウント）

## 9. キャラクター（src/core/constants.js CHARS）

絵本調・共通ルール（上から光 / 濃色アウトライン / ほっぺ / 大きな目）。全員同性能。

| idx | 名前 | 色 | あたまの飾り |
|---|---|---|---|
| 0 | ブランブル | オレンジ | ふたば (sprout) |
| 1 | ミント | グリーン | はっぱ (leaf) |
| 2 | ソラ | ブルー | しずく (drop) |
| 3 | モモ | ピンク | はな (flower) |

描画は `src/draw/chars.js drawBuddy(cx, feet, size, pal, opts)`。HUD用に `drawFaceChip`。

## 10. ステージテーマ（THEMES）

くさはら / どうくつ（暗・星） / おしろ（暗・星）。各テーマは床2色チェッカー、壁、箱、
爆風アクセント色を持つ。タイトルで固定選択 or ランダム。

## 11. サウンド

- BGM: `src/engine/audio.js`（Web Audioチップチューン、Bramble's Dashと同一エンジン）
  タイトル=`map`、ステージ= `overworld / cave / castle`（テーマ順）
- 追加SFX: `src/engine/sfx2.js`（爆発・設置・取得・カウント・GO）。audio.jsは**無改変流用**

## 12. セーブ（localStorage）

キー `brambleBoom.save`:
```json
{ "difficulty":0, "cpuCount":1, "themeSel":3, "w":0, "l":0 }
```
themeSel: 0-2=テーマ固定, 3=ランダム。読み込みは範囲クランプ。
