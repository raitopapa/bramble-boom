# Bramble Boom! — ブランブルのボムバトル 💣

ブランブルたちが対戦する、ボンバーマン型の**オリジナル**ブラウザゲームです。
タブレット・スマホでのタッチ操作を最優先に設計したキッズフレンドリーな対戦ゲーム。
[Bramble's Dash](https://github.com/raitopapa/bramble-dash) と同じ世界観・同じ技術基盤（自作バンドラ＋単一HTML配信）で作られています。

- **プレイ人数**: 1人（プレイヤー vs CPU 1〜3人）
- **対象端末**: iPad / iPhone / Android タブレット・スマホ（横向き推奨）、PCブラウザ
- **インストール不要**: `index.html` 1ファイルだけで完全に動作します

## あそびかた

- 十字キーで移動、**ボム**ボタンで爆弾を置く
- 爆弾は約2.4秒で十字方向に爆発。**やわらかい箱**を壊すとアイテムが出ることがある
- 爆風に当たるとアウト。**さいごのひとりになったら勝ち！**（制限時間2分、時間切れはひきわけ）

### アイテム

| アイテム | こうか |
|---|---|
| 💣 ボムアップ | 同時に置ける爆弾 +1（最大6） |
| 🔥 ファイアアップ | 爆風の長さ +1（最大8） |
| ⚡ スピードアップ | 移動速度アップ（最大+4） |

### なんいど（タイトルで選択）

| なんいど | プレイヤー | CPU |
|---|---|---|
| ふつう | ライフ1 | ふつうの強さ |
| やさしい5さい | ライフ2（ハート） | ゆっくり・控えめ |
| とてもやさしい3さい | ライフ3（ハート） | とてもゆっくり・ほぼ攻めない |

### そうさ

| | タッチ | キーボード |
|---|---|---|
| 移動 | 左下の十字キー | 矢印 / WASD |
| ボム | 右下の ボム ボタン | Space / Z / X |
| 決定・スタート | タップ | Enter |
| ポーズ | 右上 ❚❚ | P / Esc |

## デプロイ（GitHub Pages）

1. このリポジトリの **Settings → Pages → Deploy from a branch → `main` / `(root)`** を設定
2. リポジトリ直下に **ビルド済みの `index.html`** があればそれだけで公開されます

> ⚠️ **重要**: 公開するのは必ず**ビルド済みの `index.html`**（単一ファイル・自己完結）です。
> `index.dev.html` は開発用（ES Modules参照）なので、**これを `index.html` として置くとコードの文字がそのまま表示されます。**

## 開発

```bash
node build.mjs        # src/ → index.html（本番） & index.dev.html（開発）を生成
node test/smoke.mjs   # ヘッドレス自動テスト（実プレイ駆動＋ビルド成果物の起動確認）

# 画面の見た目をPNGで確認したいとき（node-canvasを一時インストール）
npm i canvas && node render-shot.mjs   # shots/*.png に出力
npm un canvas                          # 依存は空に戻す（配布物に含めない）
```

- ソースの正は `src/`。**`index.html` は生成物なので直接編集しない**
- 詳細仕様は [`docs/SPEC.md`](docs/SPEC.md)、設計と開発規約は [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- AIアシスタント（Claude等）で開発を続ける場合は [`CLAUDE.md`](CLAUDE.md) を最初に読ませてください

## フォルダ構成

```
index.html        ← ビルド済み・これだけで動く（公開用）
index.dev.html    ← 開発用（src/ を読む）
build.mjs         ← バンドラ / build.shell.html ← HTML+CSSの外殻
src/              ← ゲーム本体（ES Modules）
test/smoke.mjs    ← 自動テスト
render-shot.mjs   ← スクショ検証ツール（開発専用）
docs/             ← 仕様・設計ドキュメント
```
