# Bramble Boom! 🌱💥（ブランブルのボムバトル）

5さいの子どもでも すぐ遊べる、ボンバーマン風のオリジナル・ブラウザゲームです。
依存ライブラリゼロ・単一の `index.html` で動き、タブレット／スマホ／PC のどれでも遊べます。

![status](https://img.shields.io/badge/build-passing-brightgreen) ![deps](https://img.shields.io/badge/dependencies-0-blue) ![play](https://img.shields.io/badge/play-browser-orange)

---

## 🎮 コンセプト

- **ターゲット：5さい前後の小さな子ども**（とその家族）
- **やさしさ最優先**：ひらがな多めのUI、怖すぎない見た目、負けても軽い演出
- **タッチ操作ファースト**：画面の十字キー＋ボムボタン。横向き（よこむき）推奨
- **樹木医テーマ**：作者の本業（樹木医）にちなみ、なかまは「めばえの妖精」、敵は「木を食べる害虫」、ボスは「朽木（くちき）モンスター」
- **すぐ遊べる・すぐ分かる**：能力は「はやい・ボム多い・ばくはつ大きい・タフ」など、見ただけで分かるものだけ

爆弾を置いて、やわらかい箱をこわし、アイテムで強くなりながら、CPU や ボスをやっつけるゲームです。

## 👑 ボスバトル

- 大ボス **「クチキング」**（HP 8）にいどむモード。マグマステージ＋専用BGM
- プレイヤーのボムの爆風を当てるとダメージ（被弾後は約1.1秒むてき）
- ボスの攻撃：①ボム設置 ②スラム（赤い警告リング → 十字範囲の爆発）
- 撃破すると、クルクル縮んで退場 → **紙ふぶき＋★クリア！★** のお祝い演出
- プレイヤーはハート3つ、制限時間3分

## 🏗️ アーキテクチャ

### ソース構成（`src/` が「正」、`index.html` は生成物）

```
bramble-boom/
├── index.html          ← ★ビルド生成物（直接編集しない）
├── index.dev.html      ← 開発用（ES Modules を直接読み込む）
├── build.mjs           ← 自作バンドラ（src/ → index.html）
├── build.shell.html    ← HTMLの外枠＋タッチUI＋CSS
├── package.json        ← 依存ゼロ
├── docs/               ← ドキュメント
├── test/
│   └── smoke.mjs       ← スモークテスト
└── src/
    ├── core/           constants.js / utils.js / input.js
    ├── engine/         canvas.js / audio.js / sfx2.js / loop.js
    ├── game/           state.js / board.js / entities.js / ai.js / boss.js / flow.js
    ├── draw/           chars.js / render.js
    ├── scenes/         TitleScene / SelectScene / BattleScene / SceneManager
    └── main.js
```

（現在 20 モジュール）

### 依存方向

```
constants / utils → engine → state / board → entities → ai → boss → flow → draw → scenes → loop → main
```

### ビルドの仕組み

`build.mjs` が `src/` の各ファイルを **依存順（ORDER）** に連結し、`import`/`export` 行を取り除いて 1 つの IIFE にまとめ、`build.shell.html` に埋め込んで `index.html` を出力します。

> **ルール**：バンドルは単一スコープのため、**トップレベル名は全ファイルでユニーク**にする必要があります。新しいモジュールは `build.mjs` の `ORDER` に依存順で追加します。

## 📐 仕様（SPEC）

### 盤面・タイル
- タイル 16px、盤面 **15 × 13**（外周＋偶数座標が壁）
- やわらか箱の密度 62%（4隅は L字3マスを確保）
- 乱数：`mulberry32(seed)`（シード固定で再現可能）

### プレイヤー / 移動
- 移動速度：`(58 + speedUps × 13) × spdMul` px/秒（斜め 0.78 倍）
- 当たり半径 5.2px、コーナーアシストあり

### 爆弾
- 導火線 2.4秒、爆発持続 0.5秒、誘爆 0.08秒
- 初期：ボム1（上限6）／火力2（上限8）／スピード上限+4
- キック滑走速度 120px/秒

### アイテム出現重み
`bomb 0.26 / fire 0.26 / speed 0.18 / kick 0.10 / pierce 0.10 / remote 0.10`

### 難易度
| キー | 表示 | ハート | CPU速度 |
|------|------|--------|---------|
| normal | ふつう | 1 | 1.0 |
| easy5 | やさしい5さい | 2 | 0.78 |
| easy3 | とてもやさしい3さい | 3 | 0.6 |

### ボス
- HP 8（owner=9）、被弾後むてき 1.1秒、移動速度係数 0.74
- 攻撃：ボム（約3秒ごと・range2）／スラム（約6.5秒ごと・警告0.85秒→range2）
- プレイヤー：ハート3、制限180秒。HP0でクリア／ハート0・時間切れで敗北

### 制限時間
- 通常 120秒（時間切れは引き分け）

## 🚀 開発・実行

```bash
# ビルド（src/ → index.html を生成）
node build.mjs

# テスト（ヘッドレスのスモークテスト）
node test/smoke.mjs

# 遊ぶ：生成された index.html をブラウザで開くだけ
#（開発中は index.dev.html を使うと ES Modules を直接読み込めます）
```

> ⚠️ `index.html` は生成物です。直接編集せず、`src/` を編集して `node build.mjs` で作り直してください。

### 開発のお作法
- 変更ごとに `node build.mjs && node test/smoke.mjs` が緑になることを確認
- 数値・ルールを変えたら本ドキュメント（SPEC）も更新
- `package.json` の依存は常に空に保つ

## 🌐 公開（GitHub Pages × GitHub Actions）

`.github/workflows/deploy.yml` を置き、リポジトリの **Settings → Pages → Source** を「GitHub Actions」にすると、`main` ブランチへの push で自動的に：

1. `node build.mjs` を実行して `index.html` を生成
2. GitHub Pages へデプロイ

公開URLは次の形になります：

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

このURLをブラウザで開くだけで、スマホ・タブレットでも遊べます。
